# 回写与复盘模板

## 本轮目标

记录本轮要交付的最小可验证结果。

## 事实变化

- 新增或改变的项目事实
- 影响 README、specs、runbooks 或 Security 的长期约束

## 决策记录

- 采用的方案
- 拒绝的方案与原因
- 需要未来实现者保留的边界

## 验证记录

- 本轮运行的命令
- 通过结果
- 未覆盖但已知的风险

## 回写清单

- `AGENTS.md`
- `docs/specs/`
- `docs/runbooks/`
- `README.md`
- `SECURITY.md`
- `THIRD_PARTY_NOTICES.md`
