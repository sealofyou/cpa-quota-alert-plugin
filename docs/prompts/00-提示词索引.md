# 00 - 提示词索引

本仓库只保留最小提示词索引，不复制通用前端、产品或协作 prompt 全家桶。

## 使用顺序

1. 先读 `AGENTS.md`
2. 再读 `docs/specs/01-项目启动卡.md` 到 `docs/specs/05-测试与验证策略.md`
3. 涉及部署或运维时读 `docs/runbooks/`
4. 涉及复盘时使用 `docs/reviews/回写与复盘模板.md`

## 任务提示

- Scaffold 阶段：只维护公开仓库骨架和文档，不实现业务代码
- 实现阶段：先写测试，再实现纯逻辑，最后接入 ABI 与 Management routes
- 发布阶段：先本地验证，再隔离 CPA 验证，再生产 dry-run
