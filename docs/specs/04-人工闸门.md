# 04 - 人工闸门

## 必须暂停人工确认

- 准备创建公开 GitHub 远端
- 准备发布 tag 或 release
- 准备安装或加载 `.so` 到真实 CPA 实例
- 准备在 VPS1 或其他生产环境启用通知
- 发现文档、示例或构建产物包含真实凭据、真实地址、真实个人邮箱或账户标识
- 需要引入非标准库运行时依赖
- 需要改变最低兼容 CPA 版本或 ABI baseline
- 需要把套餐权重写成项目默认事实

## 可自动继续

- 修改 Harness 文档使其匹配已批准设计
- 添加或修正公开安全声明
- 添加结构检查、格式检查和占位目录
- 在本地 feature branch 上提交 scaffold 变更
- 修复 CI workflow 中明显的结构错误

## 安全边界

原生插件与 CPA 同进程运行，属于高权限扩展。任何生产安装指引都必须强调可信源码、checksum 校验、最小权限配置、脱敏日志和回滚路径。
