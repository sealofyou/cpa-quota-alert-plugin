# 05 - 测试与验证策略

## Scaffold 阶段

- `make verify`：结构检查、Go 文件格式检查、workflow 存在性检查
- `git diff --check`：空白与行尾检查
- 占位符扫描：拒绝占位标记
- 公开安全扫描：拒绝明显真实个人邮箱、IPv4、私钥块、长 Bearer 值和常见凭据赋值模式
- 人工阅读 `AGENTS.md` 与 5 个 specs 文件，确认事实与已批准设计一致

## 纯逻辑单元测试

后续实现需覆盖：

- 5h / 7d 窗口识别、百分比解析和边界值
- aliases、权重、ignored plan、未知套餐和 alias 冲突
- Plus / Team / K12 / Pro 5x / Pro 20x 的显式配置样例
- terminal error 置零、普通错误 partial、全部 unresolved 不可计算
- 1.5 / 1.6 hysteresis、首次低额度、24 小时提醒、恢复

- 通知失败、pending 重试、分通道去重
- 状态文件损坏、原子写、权限与旧版本字段兼容
