# 03 - 验收标准

## 当前 Scaffold 验收

- 仓库包含 Go module、MIT license、README、中文 README、Security、Third Party Notices、CI 和 release workflow
- Harness 文档完整覆盖项目目标、MVP 范围、验收标准、人工闸门、测试策略、部署与运维入口
- 计划中的代码目录存在占位文件，但不存在空 Go 包或伪业务实现
- CI 在没有业务包时仍能执行结构和格式检查
- 文档不包含占位标记
- 文档不包含真实凭据、真实地址、真实个人邮箱或生产账户标识
- Git 仓库默认分支为 `main`，工作分支为 `codex/initial-implementation`
- 完成一个 Lore Protocol commit

## v0.1 功能验收

- 只监控 CPA 中启用的 Codex 凭据
- 每 5 分钟可得到一次可解释的 Plus 周额度等价值
- 总额度低于 `1.5` 时告警，持续低额度每 24 小时提醒，达到 `1.6` 后恢复
- 单账号错误只影响该账号折算，不单独打扰用户
- 连续三次无法形成可信额度时，只发送一次监控异常事件，恢复后才允许下一轮异常事件
- 未识别套餐不猜权重，不计算本轮总额度，并发送一次路径变化提醒
- 未配置通知时仍可作为只读额度检查器使用
