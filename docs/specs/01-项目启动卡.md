# 01 - 项目启动卡

## 项目名称

CPA Quota Alert Plugin

## 仓库与模块

- 公开仓库目标：`github.com/sealofyou/cpa-quota-alert-plugin`
- Go module：`github.com/sealofyou/cpa-quota-alert-plugin`
- 许可证：MIT
- 当前阶段：pre-alpha 工程 Harness 与公开仓库骨架

## 项目目标

把已验证的 Codex 额度低噪声告警规则，重做为 CLIProxyAPI 原生 C ABI v1 动态插件。插件运行在 CPA 宿主进程内，通过 Host Callback 读取启用的 Codex 凭据并查询额度，再通过受 Management API 保护的路由提供检查、状态和测试通知能力。

## 目标用户

- 使用 CLIProxyAPI 管理 Codex 凭据池的个人或小团队运维者
- 能理解原生插件同进程高权限风险，并愿意校验源码或 release checksum 的 CPA 管理者

## 第一版本技术边界

- 语言：Go
- 运行时目标：Go 标准库
- 插件形态：Linux amd64 `.so`
- 构建方式：未来使用 `-buildmode=c-shared`
- 最低兼容：CPA `v7.2.83`
- 兼容测试：CPA `v7.2.120`
- ABI：CLIProxyAPI C ABI v1

## 公开声明

本项目不是 OpenAI 官方项目，也不是 CLIProxyAPI 官方项目。`wham/usage` 是内部后端接口，响应结构可能变化。套餐权重和终态错误均由运行者配置，公开示例不得被写成官方事实。
