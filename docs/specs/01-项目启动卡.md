# 01 - 项目启动卡

## 项目名称

CPA Quota Alert Plugin

## 仓库与模块

- 公开仓库：`github.com/sealofyou/cpa-quota-alert-plugin`
- Go module：`github.com/sealofyou/cpa-quota-alert-plugin`
- 许可证：MIT
- 当前阶段：v0.1 release candidate；实现与隔离 CPA 验证已完成，生产上线 Gate 仍未关闭

## 项目目标

把已验证的 Codex 额度低噪声告警规则，重做为 CLIProxyAPI 原生 C ABI v1 动态插件。插件运行在 CPA 宿主进程内，通过 Host Callback 读取启用的 Codex 凭据并查询额度，再通过受 Management API 保护的路由提供检查、状态和测试通知能力。

## 目标用户

- 使用 CLIProxyAPI 管理 Codex 凭据池的个人或小团队运维者
- 能理解原生插件同进程高权限风险，并愿意校验源码或 release checksum 的 CPA 管理者

## 第一版本技术边界

- 语言：Go
- 运行时目标：Go 标准库与 `gopkg.in/yaml.v3 v3.0.1`
- 插件形态：Linux amd64 `.so`
- 构建方式：Linux amd64 `-buildmode=c-shared`
- 最低兼容：CPA `v7.2.83`
- 兼容测试：CPA `v7.2.120`
- ABI：CLIProxyAPI C ABI v1

## 公开声明

本项目不是 OpenAI 官方项目，也不是 CLIProxyAPI 官方项目。`wham/usage` 是内部后端接口，响应结构可能变化。套餐权重和终态错误均由运行者配置，公开示例不得被写成官方事实。

## 当前交付物

当前已交付 v0.1 候选实现、测试、公开安全示例、systemd 资产、README、Security、Third Party Notices、CI 与 tag release workflow。Windows `go test` / `go vet` / `scripts/verify.ps1` 已通过；隔离 Linux 环境中 `go test ./...`、`go test -race ./...`、`go vet ./...` 和 Linux amd64 c-shared 构建已通过。官方 CPA `v7.2.83` 与 `v7.2.120` 的两个 loopback 实例均已真实加载插件，并通过 Management 鉴权、正常 2.1 混合窗口、partial 2.0、终态置零、未知套餐、第三次失败一次 `data_error`、低额/恢复、stale、并发 409 与 root-only SMTP 隔离配置的 `test-notification` delivered 检查。
